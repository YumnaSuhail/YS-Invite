# Yumna & Suhail – Wedding Invitation

A single-page animated wedding invitation.

## Files
- `index.html` – the invitation (HTML, CSS and JS)
- `assets/` – photos, wax seal image and the song (`song.mp3`)

## View it online (GitHub Pages)
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Your invitation will be live at `https://<your-username>.github.io/<repo-name>/`.

## Run locally
Open `index.html` in a browser. If the music doesn't play, serve the folder instead:

    python3 -m http.server 8000

then visit http://localhost:8000
